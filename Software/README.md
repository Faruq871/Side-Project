# Software

A collection of technical references, usage guides, and practical code examples covering programming languages, software libraries, and database technologies.

## Contents

| Directory | Description |
|---|---|
| `Python Libraries/` | Jupyter notebooks covering Python libraries, data analysis tools, visualization, statistical modeling, and interfaces to other language runtimes. |
| `R Packages/` | R package references and RMarkdown documentation covering data manipulation, visualization, and analysis. |
| `SQL Ecosystem/` | Technical references covering SQL fundamentals, database systems, analytical databases, query engines, and database internals. |

## Usage

Each directory contains its own documentation, code examples, and usage instructions. Refer to the README or documentation within each directory for specific prerequisites, dependencies, installation instructions, and execution guidelines.
