# Notebooks

Keep each notebook focused on one question. Move reusable code into `src/` or dbt models.

- `analysis/`: data checks, exploration, metrics, and charts.
- `prediction/`: statistical analysis, feature preparation, and prediction.
- `modeling/`: model training, evaluation, and saved models.

Suggested names: `01_data_overview.ipynb`, `02_delivery_analysis.ipynb`, `03_late_delivery_prediction.ipynb`.
